# First Web Portfolio 🚀

This is my first dev project front-end, created to consolidate all my basic knowledges in HTML and CSS only. It focus on styling, interactiveness and structure. All made manually from scratch.

## 📌 About the project

This project was developed as the final assignment for my first academic term. It serves as a comprehensive evaluation to consolidate everything I learned in HTML, CSS, and JavaScript over the first three months.

## 🛠️ Technologies Used

- **HTML5:** Semantic content structuring.
- **CSS3:** Styling, layout, and responsiveness.
- **Git & GitHub:** Version control and hosting.
- **VS Code:** Primary IDE used for development.

## 🧠 Key Learnings & Challenges

During development, I focused on:

1. **Web Design and SEO Structure:** Here I focused in a clear structure and had to attend to a list of features that my page needed to have. I explored many possible ways to improve the website.

2. **Professional Versioning:** I started learning about Git and versioning management last week, so I decided to pull this projetct to GitHub to practice using all the Git Bash lifecycle, including commands like `init`, `add`, `commit`, and `push`.

3. **DevOps Mindset:** Implementing naming conventions for files and directories—avoiding spaces and special characters—to ensure clean and script-friendly organization.

## 📂 How to view the project

Since this is a static project, you can simply clone the repository and open the `index.html` file in your browser:

git clone [https://github.com/lleal-dev/first-web-portfolio.git](https://github.com/lleal-dev/first-web-portfolio.git)
